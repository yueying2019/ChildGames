## 小程序备案「备注」文案（已交付三版）

用户要为 ICP 备案填「小程序备注」。先核对项目实际能力再落笔（备注与实测不符会被驳回）：
- `WeChatMiniGameBridge` 只用了 HideLoadingPage / 中文字体 / 隐私协议，**无 getUserInfo、无分享、无登录、无支付、无云开发**。
- 全项目无 UnityWebRequest/WWW → **无自主联网**。
- `AdCatalog` 三个广告位 ID 仍为空 → 当前实际无广告接入。

三版文案（字数含标点，系统限制 20–200）：
- A 推荐版 191 字 / B 详细版（河南等严格管局）197 字 / C 极简版 143 字。
- 统一口径：休闲益智单机消除三玩法 + 体力/道具/金币/每日任务 + 金币仅游戏内免费获得
  + 不涉及人民币充值与虚拟交易 + 无注册登录/信息发布/社交分享/用户间交互 + 不涉及前置审批领域。

### 备案口径要点（下次可直接复用）
- 备注**必填**、20–200 字，是主管部门审核重要依据；填在「备案小程序信息-备注」，别填到主体备注。
- **个人主体禁词**：经营/销售/商城/商贸/公司/集团等（不能出现经营性、单位性质表述）。
  「不涉及人民币充值」这类**否定式表述是允许的**（官方示例里有）。
- 服务内容标识：个人主体**不得选经营性、企业/单位性质、需主管部门审批**的类目；
  有版号或已完成「小游戏备案」的由平台默认填「休闲娱乐-游戏」；无版号其他小游戏建议「生活服务-工具」。
- 前置审批：小游戏 IAA 通道需先完成「小游戏备案」，ICP 备案里前置审批勾"是"、类型"出版"，材料平台自动同步。
- 各省特殊：**河南**要求备注把玩法写细；**天津**备注位置改成「前置审批备注」且只写应急电话使用人
  （个人主体须直系亲属并说明关系）；**广东**要按最新模板交备案承诺书。

## 首版提审文案（新文件 `Tools/首版提审文案.md`）

用户问首版提审怎么写。产出：8 项提审前自检表 + 上传项目备注 + 名称/简介/类目/标签
+ 提审页「功能描述 / 测试账号 / 审核备注（详细 320 字 + 精简 180 字）」+ 5 张截图脚本
+ 60 秒录屏脚本 + 本项目专属风险表 + 驳回对照表。

### 提审口径（下次复用）
- 本项目提审优势：无登录、无注册、无分享、无 UGC、无支付、**不采集任何用户信息**
  （`WeChatMiniGameBridge` 只调 `RequirePrivacyAuthorize`）→ 备注里要主动写明，能显著降驳回率。
- 版本描述三处不同：开发者工具「项目备注」= 本次改了什么；后台「游戏简介」= 玩法广告语（≤100 字）；
  提审页「审核备注」= 给审核员的说明书（玩法/账号/隐私/商业化/素材逐条列）。别三处写一样。
- 广告话术必须写清：激励视频**用户主动点击触发、可跳过可关闭**；插屏**仅返回选关时、有频控**；
  Banner**不遮挡操作按钮**。这是"广告违规"驳回的唯一有效预防。
- 本项目当前卡点：`AdCatalog` 三个广告位 ID 为空 → 广告整体降级关闭。
  ID 是 const，改了必须重新出包提审；若已开流量主就首版填好，否则过审后再发一版补。

### 提审页字段顺序与「版本更新说明」（官方资质指引核验后修正）
- 提审页字段顺序：小游戏类目 → **游戏引擎** → **版本更新说明** → 资质文档 → 测试号。
- **资质口径修正（重要）**：官方《小游戏资质提交审核指引》明确
  **《游戏自审自查报告》是所有游戏首次提审的必填项**（原件或本人亲笔签名复印件扫描件，
  jpg/png/bmp/gif，≤5M）；《计算机软件著作权登记证书》**选填**，仅牌类/捕鱼类必填。
  之前写的"软著或自审报告按提示补"是错的，已改为自审报告必填、软著选填。
- 「版本更新说明」定位 = **给审核员的验收清单**，写法 `模块 + 改了什么 + 测试路径`；
  与「审核备注」（说明游戏是什么）完全不同，别混写。
  禁"优化体验/修复若干 bug"空话；动词开头（新增/优化/修复）；合规点单独成条；版本号必须递增。

## 推广素材生图提示词（新文件 `Tools/推广素材生图提示词.md`）

管理端路径「功能-游戏能力地图-运营素材管理」的通用素材三项：封面 / 详细推广图竖版 / 详细推广图横版。

### 规格口径（官方可查部分）
- 《游戏实机素材指南》：封面横版 16:9 = 1920×1080、竖版 9:16 = 1080×1920、**JPG <500K**。
- 「通用素材」三项像素以上传页实际提示为准，**比例对就行**，出图后裁切压缩。
- 版面硬性要求：**至多 1~2 个视觉焦点**；除游戏名外禁一切文案；禁按钮/血条/分数等 UI；
  禁边框、黑边、加载转场；禁直接用游戏 icon 或截图；画风要与实机延续。

### 本项目视觉符号（三图共用，保证像一个游戏）
三消=糖果果冻方块(粉/薄荷/天蓝/柠檬黄)；对对消=成对果蔬+折线发光连(橙/草绿/奶油白)；
叠叠消=三层堆叠圆角卡牌+木质暂存槽(原木棕/奶白/暖橙)。统一马卡龙糖果色、扁平+轻3D卡通、明亮暖背景。

### 生图通用做法
- prompt 结构 = 主体描述 + 构图 + 公共风格后缀（英文），**统一 negative 禁 text/letters/logo/UI/真人/边框**。
- **AI 不生成任何文字**，游戏名一律后期加（AI 写中文必崩，也正好符合"禁营销文案"）。
- 出图主体占比 ≤70%，方便裁切；导出 JPG 质量 80-85 压到 500K 内。
