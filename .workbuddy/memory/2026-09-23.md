## 商店道具图标（Item 预制体 + 编辑器脚本绑定）

用户把 Shop 商品行模板 ItemTemplate 改造了：删掉行内 Title 文本，改挂一个 Item 预制体实例
（`Assets/Content/UI/Item.prefab`，引用 guid `b5a99db6c5c80764d8d31ce8758939b1`，
结构：Item 56×56 → IconBg(Image) + Icon(Image, 44×44)）。三个 GameView 的道具按钮同样换成了这个实例。

### 改动

  `Bind(ShopItemInfo)` → `Bind(ShopItemInfo, Sprite)`；Awake 时没拖引用就按子节点名 "Icon" 兜底查找。
- `UI/Panels/ShopPanel.cs`：加 `[Serializable] struct ShopIconEntry{ShopItemId Id; Sprite Icon}` +
  `public ShopIconEntry[] Icons` + `IconOf(id)`；两处 Bind 调用都传图标。
- `Editor/ShopIconBinder.cs`（新）：菜单「SmallGames/绑定商店道具图标」，按
  `Assets/UI/<玩法>/<ShopItemId>.png` 用 `AssetDatabase.LoadAssetAtPath<Sprite>` 填 Icons，
  并顺手把模板的 IconImage 指向 Item 实例里的 Icon；缺图会弹窗列出。

### 关键结论（踩到的坑）
1. **资源引用用的 32 位十六进制 guid，和 .meta 里那个 56 位 base64 串不是一回事**，互相推导不出来。
   所以 Python 脚本**没法**算出图标的引用 guid —— 凡是「往预制体里写资源引用」的活，
   改用编辑器脚本让 Unity 自己解析路径，别手算 guid。
2. YAML 里嵌套预制体实例的内部对象写成 `--- !u!224 &id stripped`（只有
   m_CorrespondingSourceObject / m_PrefabInstance / m_PrefabAsset 三行）。
   **块切分正则必须认 `(?: stripped)?`**，否则这些 id 全被误判成悬空引用。
   `verify_new_tools.py` / `audit_prefab_graph.py` 这类脚本都要跟上。
3. 实例的属性覆盖读 1001 PrefabInstance 块的 `m_Modifications`，target 用源预制体里的 fileID
   （Item.prefab：根 Rect=5934839101267530661、Icon Image=5572156852717320087）。

## 图集打包编辑器扩展（Editor/SpriteAtlasBuilder.cs，新）

需求：一键把指定文件夹里所有图片打成图集。

### 关键结论
- 团结引擎把 `UnityEditor.U2D.SpriteAtlasExtensions` 放进了 **`Unity.InstantGame.Editor.dll`**
  （`Library/ScriptAssemblies` 里只有这一个 dll 含该符号，Unity.2D.Sprite.Editor.dll 里没有）。
  为了不引这个程序集，改成**纯文本方案**：写 `.spriteatlasv2` 的 YAML + 改同名 `.meta` 里的
  importer 字段。asmdef 一行都不用动。
- Sprite Atlas V2（`.spriteatlasv2`）本体只有 `m_ImporterData.packables`（每项
  `- {fileID: 2800000, guid: <32 hex>, type: 3}`，fileID 2800000 = 纹理主对象）；
  **真正的打包参数全在 `.meta` 的 `SpriteAtlasImporter` 段**：textureSettings
  （maxTextureSize/compressionQuality/crunchedCompression/filterMode/generateMipMaps）、
  packingSettings（padding/blockOffset/enableRotation/enableTightPacking/enableAlphaDilation）、
  `bindAsDefault`（= Include In Build）。改完 meta 要再 `Refresh()` 让 Unity 重读。
- 生成顺序：先写 atlas 文件 → `Refresh()`（Unity 生成 .meta）→ 改 meta → `ImportAsset(ForceUpdate)`
  → 再 `Refresh()`。覆盖写 atlas 时**别删 .meta**，guid 不变，Addressables 条目不会断。

### 实现
`Assets/Scripts/Editor/SpriteAtlasBuilder.cs`，命名空间 `SmallGames.Editor`：
- 菜单「SmallGames/图集打包工具」开窗口；「SmallGames/为选中文件夹生成图集」+ `Assets/` 右键菜单
  直接用保存的参数跑（参数存 EditorPrefs，key `SmallGames.SpriteAtlasBuilder.Settings`，JsonUtility）。
- 窗口：源文件夹列表、每文件夹一个图集/合并成一个、输出到源文件夹内/统一目录、含子文件夹、
  图片导入强制改成 Sprite（TextureImporter）、Max Size/Padding/Filter/压缩质量/MipMaps/
  旋转/紧凑/Alpha 膨胀/IncludeInBuild、可选登记到 Addressables 分组（默认 core_ui，默认关）。
- 报告里给每个图集的精灵数与 Max Size 容量占用百分比，超过 100% 给拆图集警告。
- 「清理失效条目」：扫 packables 里 guid 对应资源已不存在的行并删掉。

## 三玩法闲置 15 秒的闪烁提示

需求：15 秒没有成功消除，就闪一下「该消哪张/哪组牌」，帮助卡顿的玩家。

### 新增两个通用件
- `UI/HintFlash.cs`（静态）：给一批 `Graphic` 做限时明暗呼吸（周期 0.42s、最低 alpha 0.25、默认 3.2s）。
  借 `UITween.Custom(graphic, duration, apply, Linear)` 驱动，不自己开 Update；到期或 Stop 都会还原原色。
  `RestoreIfPlaying(graphic)` 给「对象回池/销毁前」用，避免池里留半透明的牌。
- `Gameplay/IdleHintTracker.cs`：15 秒（`DefaultSeconds`）计时器；`Tick(dt)` 到点返回 true 并自动清零
  （玩家继续不动会再提示一轮）；`Reset()` 在结算/锁输入/播放动画时调用。

### 三个 View 的接法（后续改好照抄）
- 字段 `private readonly IdleHintTracker _idle = new IdleHintTracker();`；`Update()` 里挂 `TickIdle()`。
- `TickIdle()`：`_busy/_matching/_linking || _ended || InputLocked || engine 空` → Reset + HintFlash.Stop；
  否则 Tick 到点就出提示。（三个 Session 暂停时都会把 `InputLocked` 置 true，所以暂停自动不计时 ✓）
- 重置时机＝**真的消掉了东西**：Match3 在 `PlayEvents` 里用 `HasClear(result)` 判 thế Remove/Blast 事件；
  Lianliankan 在 `NoteCombo()`；Sheep 在 `PlayMatch()` 开头。另外各自 StartPlay/清理/回池处都 Stop 一次。
- 提示目标：Match3 用 `_engine.TryGetHint` 两张；LLK 用 `_engine.TryHint`（失败先 `EnsurePlayable(true)`）
  取 `GetTile(r,c)` 的 Icon；Sheep 见下。

### Sheep 的提示怎么算（`SheepGameView.FindHintGraphics`）
1. 先找「槽里差一张」的组合：统计槽里各 iconId 数量 == MatchUnit-1 且场上有同 id 可点牌 → 闪槽内这些 + 那 1 张。
2. 否则找「够数的一组可点牌」：need = MatchUnit - 槽内同 id 数，且 `_slots.Count + need <= _slotLimit`（槽满了就不提示）。
3. 都找不到返回 null —— 全被压住时不硬闪。可点判定 `CanTap = activeSelf && !InSlot && !Locked`。

### 顺手发现（未改，已知会 Bug）
`SheepGameView.TryTakeMatch` 里合成门槛**写死 3**，没用关卡的 `_compose`；也就是说 ComposeNum=4 的「四同变体」
实际仍是 3 张就消。新加的 `MatchUnit` 常量特意跟它对齐（也是 3），注释已写明。要修的话两边一起改。
