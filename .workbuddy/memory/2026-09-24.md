## 微信小游戏个人主体上架合规（资料收集）

- 官方《小游戏入驻指南》口径：**企业主体必须做微信认证，个人主体自行选择**；未认证的账号没有「被分享」和「被搜索」能力。办结 1-3 工作日。
- 微信认证个人材料：身份证正反面（有效期 > 1 个月）、姓名+身份证号、管理员微信扫码核验、个人仅支持电子发票、费用 30 元/次（企业 300，审核失败不退）。
- 主体资质门槛：**18 岁以上、有中国大陆居民身份证的微信实名用户**（腾讯客服原话）。
- 上线必经（走 IAA 无虚拟支付通道，本项目适用）：
  1. 资质管理上传：游戏自审自查报告（线上确认签名）、代备案授权书/著作权自我声明（扫码签署）；**名称含英文或"软件"字样、涉及品牌/公众人物时必须补软著**。
  2. 小游戏备案 → 小程序备案（管局下发备案号后才能发布）。
  3. 版本审核前必须先完成**适龄提示**设置并通过审核（约 1 工作日）。
- 对项目的硬提醒：`GameBootstrap` 里隐私同意流程被注释 → 缺《用户隐私保护指引》提审必被驳回，做上架前必须先补。
- 个人主体**不能开通虚拟支付**，只能广告变现（流量主需累计独立访客 1000）；带内购必须企业主体 + 版号。已删的 378Q 棋牌正是个人主体禁区。

## 微信广告 SDK 真实签名核对（com.qq.weixin.minigame v0.1.32）
核对方式：`Library/PackageCache/com.qq.weixin.minigame@.../Runtime/Plugins/wx-runtime{,-editor}.xml` 里的 XML 文档 = 精确签名来源，比猜和搜博客都准。
- `WXBase.cs` / `WX.cs` 都有 `#if UNITY_WEBGL || WEIXINMINIGAME || UNITY_EDITOR`；`public class WX : WXBase`，
  所以 `WX.CreateRewardedVideoAd` 是**继承来的静态**，反射必须带 `FlattenHierarchy` 才找得到。
- 广告类**都继承 `WXBaseAd`**：`WXRewardedVideoAd` / `WXInterstitialAd` / `WXBannerAd` / `WXCustomAd`。
- **`WXBaseAd.Show` 只有两个重载，都是成功/失败双回调**：
  - `Show(Action<WXTextResponse> succ, Action<WXTextResponse> fail)`  ← 2 参
  - `Show(string branchId, string branchDim, Action<WXTextResponse>, Action<WXTextResponse>)` ← 4 参
  **没有 `Show()`、也没有 `Show(Action<WXADErrorResponse>)`**。show 失败只带 `errMsg`，不带 errCode。
- `WXRewardedVideoAd`：`Load(Action<WXTextResponse>, Action<WXADErrorResponse>)`、`OnClose/OffClose(Action<WXRewardedVideoAdOnCloseResponse>)`（该响应有 **field** `isEnded`）、`ReportShareBehavior`。
- `WXInterstitialAd`：`Load(同上)`、`OnClose/OffClose(Action)`（**非泛型 Action**）。
- `WXBannerAd`：`Hide()`（0 参）、`OnResize/OffResize`；Show 走基类。`WXCustomAd.Hide(Action<WXTextResponse>, Action<WXTextResponse>)`。
- `WXBaseAd` 还有 `OnLoad/OffLoad(Action<WXADLoadResponse>)`、`OnError/OffError(Action<WXADErrorResponse>)`、`Destroy()`。
- 创建：`WX.CreateRewardedVideoAd(WXCreateRewardedVideoAdParam)`、`CreateInterstitialAd(WXCreateInterstitialAdParam)`、
  `CreateFixedBottomMiddleBannerAd(string adUnitId, int adIntervals, int height)`。Param 有 `adUnitId` / `multiton` 字段。
- 类型在 Editor 下是存在的（`wx-runtime-editor.dll` 仅 Editor 启用）→ **直接引用编译不过的真实原因是本项目
  `SmallGames.Runtime.asmdef` 没引 `Wx` 程序集**，不是"类型不存在"（README 里那句说法是错的）。

## Tools/WeChatAdKit 审查结论
- **P0：`FindMethod(type,"Show",0,1)` 恒返回 null**（真实是 2/4 参）→ 三类广告全都弹不出来，且不报错，极难排查。
- P1：插屏 `_lastInterstitialAt` 在 Show 前写入（失败也占频控）；`Available` 只判激励视频；没注册 `OnError`；
  `ShowRewarded` 无重入保护；`OnClose` 注册失败时静默 → 看完广告无回调、流程卡死。
- P2：`MakeGenericMethod` + `Delegate.CreateDelegate` 在 IL2CPP/WASM 下有 AOT 风险，需真机验证。
- 尚未安装进项目（只在 `Tools/WeChatAdKit/src`，`Assets/Scripts/Platform` 下没有 WeChatAdBridge）。
