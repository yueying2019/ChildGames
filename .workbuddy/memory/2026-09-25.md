## 三玩法固定排布教学关（第 0 关）+ 强制手把手引导 + 三星条件 + 首次三星满体力

用户选型：强制手把手（遮罩+门控+可跳过）／新增前置第 0 关（不占星级、不计解锁）／每关首次三星各发一次满体力。

### 新增文件
- `Gameplay/TutorialCatalog.cs`：三玩法教学关的固定排布数据 + 通关状态 + `LevelId=0`/`Index=-1` 双哨兵
- `UI/Tutorial/TutorialStep.cs` / `TutorialScript.cs` / `TutorialDirector.cs` / `TutorialOverlay.cs`：强制引导框架

### 关键设计（踩过的点）
- **index 哨兵**：教学关 `LevelIndex = -1`，「下一关」+1 正好到第 1 关，不用单独写跳转；
  但三个 Session 的 `StartNextLevel()` 必须 `IsTutorial = false`，否则循环进教学关。
- **叠叠消棋盘可解性硬约束**：`ComposeNum=3` 时每种图案张数必须是 3 的整数倍。
  最初设计 4×4 共 12 张（每种 4 张）→ 消一组后剩 1 张凑不成，关卡卡死。改成 3×3 共 9 张（每种 3 张）。
- **门控用图案 id 不用格子索引**：叠叠消的牌一进槽就从 `_boardTiles` 摘掉，索引整体前移，第二张必然错位。
- **挖洞必须可穿透**：`GuideHighlight.SetPassThrough(true)` 关掉全屏 Catcher、改由四块遮罩吃点击
  （给 blocks 加了 Button 才能消费事件）。多目标时挖包围盒大洞（`Show(RectTransform[], shape)` 新重载）。
- **HintFlash 加了 PlayLoop**：教学要一直闪到 Stop；闲置提示的 `TickIdle` 里 `HintFlash.Stop()` 会掐掉引导高亮，
  所以三个 GameView 的 TickIdle 开头加了 `if (TutorialDirector.Active) { Reset; return; }`（且不调 Stop）。
- **每份脚本只锁第一步**：掉落补块后棋盘不再确定，锁死会变成「点不动」。

### 第三轮返工（真机试玩反馈，2 个 bug）
1. **叠叠消教学关 9 张牌叠一起**：`FixedCells` 的 `GridX/GridY` 不是棋盘格索引，
   是 `SheepBoardBuilder.GridSize=24` 的**画布网格**（牌中心 = Grid+1.5，宽约 2.7 格）。
   写 0..2 会全挤进左侧 8% 宽度。已改 {6,11,16}（中心 7.5/12.5/17.5，间距 5 格，居中）。
   ⚠️ 三玩法坐标语义：Match3/Lianliankan 的 (x,y) 是格子索引，Sheep 的是画布网格——只有 Sheep 特殊。
2. **三消步数关永远 1 星 + 「剩余 0 步」**（比文案严重）：胜利动画 `PlayLeftoverBonus` 在 `Won?.Invoke()`
   **之前**把 `MovesLeft` 转特效并 `SetMovesLeft(0)`，结算读到的恒 0。
   修：`Match3Engine.Finish` 判定 Won 时快照 `MovesLeftAtWin`；Session 评星/文案走
   `StarsMovesLeft`（AtWin>0 用快照，否则退回 MovesLeft=0 的失败语义）。
   教训：**结算读引擎状态前，先确认动画协程有没有改它**；评星数据要在「判定胜负那一刻」快照。
