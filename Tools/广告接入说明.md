# 广告接入说明（2026-09-24）

微信小游戏广告（`com.qq.weixin.minigame` v0.1.32）在本项目中的接入方式、主要函数与点位。

## 一、三层结构

业务代码只调 `AdDirector`，不直接碰 SDK。

```
UI / Session（点位）
      ↓ 只调
Core/AdDirector.cs        隐私门禁 + 点位封装 + 降级
      ↓
Platform/WeChatAdBridge.cs  强类型直连 WeChatWASM（#if UNITY_WEBGL || WEIXINMINIGAME）
      ↓
WeChatWASM.WX（SDK）
```

配置集中在 `Data/AdCatalog.cs`：**广告位 ID 留空 = 该类广告整体关闭**，流程不受影响。

| 层 | 文件 | 职责 |
|---|---|---|
| 配置 | `Data/AdCatalog.cs` | 三个广告位 ID、插屏频控、Banner 刷新间隔/高度、翻倍倍数 |
| 调度 | `Core/AdDirector.cs` | 隐私门禁、点位语义、奖励计算 |
| 桥接 | `Platform/WeChatAdBridge.cs` | 创建/加载/展示/回调，异常兜底 |
| 通用桥（旧） | `Tools/WeChatAdKit/src/WeChatAdBridge.cs` | 反射版，跨项目分发用，**当前项目不再使用** |

## 二、AdCatalog（配置）

| 成员 | 默认 | 说明 |
|---|---|---|
| `RewardedAdUnitId` | `""` | 激励视频广告位（复活 + 双倍金币） |
| `InterstitialAdUnitId` | `""` | 插屏广告位（结算返回选关） |
| `BannerAdUnitId` | `""` | Banner 广告位（大厅/选关） |
| `InterstitialMinIntervalSeconds` | `90` | 插屏最小间隔，防连点刷屏 |
| `BannerAdIntervals` | `30` | Banner 自动刷新，微信要求 ≥30 |
| `BannerHeight` | `100` | Banner 高度（像素） |
| `DoubleRewardMultiplier` | `2` | 双倍金币倍数 |
| `HasRewarded` / `HasInterstitial` / `HasBanner` | — | ID 非空即 true |

> 这些是 `const`，在 Runtime 主包里，**改动要重新提审**，上线前一次填对。

## 三、WeChatAdBridge（底层，业务一般不用）

| 函数 | 说明 |
|---|---|
| `bool Available` | 当前环境能否展示。**编辑器 / 非小游戏平台恒 false**（设计如此，不是 bug） |
| `string RewardedAdUnitId / InterstitialAdUnitId / BannerAdUnitId` | 由 `AdDirector.Initialize()` 从 `AdCatalog` 灌入 |
| `void PreloadRewarded()` | 预创建 + 预加载激励视频，隐私同意后调一次 |
| `void ShowRewarded(Action onRewarded, Action onUnavailable = null, Action onAbandoned = null)` | 看完发奖；中途退出走 `onAbandoned`；不可用/展示失败走 `onUnavailable` |
| `void ShowInterstitial(int minIntervalSeconds = 90)` | 插屏，**展示成功才更新频控时间戳**（失败不占额度） |
| `void ShowBanner(int adIntervals = 30, int height = 100)` | 固定底部居中 Banner |
| `void HideBanner()` | 隐藏 Banner |

内部：`EnsureRewarded()` 会强制注册 `OnClose`，**注册失败直接判定为不可用**（否则玩家看完广告没有回调，流程卡死）；`_rewardedShowing` 防重入；`OnClose` 里按 `res.isEnded` 分支发奖/放弃，并在关闭后自动预加载下一支。

SDK 关键签名（以 `Library/PackageCache/com.qq.weixin.minigame@*/Runtime/Plugins/wx-runtime*.xml` 为准）：

- `WX.CreateRewardedVideoAd(new WXCreateRewardedVideoAdParam { adUnitId = ... })`
- `WXBaseAd.Show(Action<WXTextResponse> succ, Action<WXTextResponse> fail)` —— **只有 2 参/4 参，没有 `Show()`**
- `WXRewardedVideoAd.OnClose(Action<WXRewardedVideoAdOnCloseResponse>)`，响应有 `isEnded`
- `WXInterstitialAd.OnClose(Action)`（非泛型）
- `WX.CreateFixedBottomMiddleBannerAd(adUnitId, adIntervals, height)`

## 四、AdDirector（业务唯一入口）

| 成员 | 说明 |
|---|---|
| `bool CanShow` | `PrivacyRepository.HasAgreed && WeChatAdBridge.Available` —— 隐私门禁 |
| `bool RewardedReady` | `CanShow && AdCatalog.HasRewarded` |
| `void Initialize()` | 灌广告位 ID + 预加载激励视频。在隐私同意之后调用（`GameBootstrap.EnterMainMenu`） |
| `void ShowLobbyBanner()` | 大厅类界面显示 Banner |
| `void HideBanner()` | 离开大厅/进玩法前隐藏（无条件调用，不判门禁） |
| `void ShowInterstitialAfterResult()` | 结算页关闭后插屏，内置频控 |
| `void WatchRewarded(onRewarded, onUnavailable, onAbandoned)` | 看激励视频拿奖励；不可用时直接 `onUnavailable`，由调用方降级 |
| `int DoubleRewardBonus(int coinsGained)` | 双倍奖励**补发差额**（`ReportResult` 已发过一次，所以是 `× (倍数-1)`） |

## 五、四个点位与调用链

### 1. 激励视频 · 看广告复活

```
失败 → GameSessionBase.OfferContinue(message)
        └─ ContinuesUsed >= MaxPerAttempt(2) 且 AdDirector.RewardedReady
              → Open(Continue, ContinuePayload{ UseAd = true, Price = 0 })
ContinuePanel.OnOpen   按 UseAd 改标题/按钮文案（"看广告复活" / "看广告"）
ContinuePanel.OnPayClicked → GameManager.ConfirmAdContinue()
GameManager.ConfirmAdContinue → AdDirector.WatchRewarded(
        onRewarded:   关闭面板 → session.AdContinue()
        onUnavailable: Toast「广告还没准备好」
        onAbandoned:   Toast「要看完广告才能复活哦」)
GameSessionBase.AdContinue()  ContinuesUsed++ → ApplyContinue()
```

`AdContinue()` **不扣金币但计入 `ContinuesUsed`** —— 降星规则看的是这个计数，不计的话能靠刷广告保三星。

### 2. 激励视频 · 结算双倍金币

```
ResultPanel.OnOpen → RefreshDoubleButton(data)
      bonus = AdDirector.DoubleRewardBonus(data.CoinsGained)
      仅 bonus>0 && RewardedReady 时显示 DoubleButton（否则整颗隐藏）
点击 → AdDirector.WatchRewarded(onRewarded: 立即清零 _doubleBonus + 隐藏按钮 + CoinWallet.AddCoins(bonus))
```

发完后立刻清零并藏按钮，防连点重复发奖；`MessageText` 追加一行提示 + Toast。

### 3. 插屏 · 结算返回选关

```
ResultPanel.OnClose → if (_leaveToLobby) AdDirector.ShowInterstitialAfterResult()
```

只在「返回选关」这条路径弹。**点「下一关 / 再来一局」后弹广告会命中运营规范 2.10.2**（点击开始/继续游戏按钮却打开广告）。

### 4. Banner · 大厅与选关

| 时机 | 调用 |
|---|---|
| `MainMenuPanel.OnOpen` | `AdDirector.ShowLobbyBanner()` |
| `MainMenuPanel.OnClose` | `AdDirector.HideBanner()` |
| `LevelSelectPanel.OnOpen` | `AdDirector.ShowLobbyBanner()` |
| `GameHudPanel.OnOpen` | `AdDirector.HideBanner()`（双保险：进玩法绝无 Banner） |

Banner 是原生层，会盖住游戏画面，进玩法前必须隐藏。

## 六、隐私门禁（硬要求）

```
GameBootstrap.ContinueFromSplash()
   ├─ PrivacyRepository.HasAgreed → EnterMainMenu(true)
   └─ 否则 → Open(UIPanelId.Privacy)
GameBootstrap.EnterMainMenu() → AdDirector.Initialize()
```

广告属第三方 SDK，**必须在用户同意隐私政策之后才允许初始化和展示**。原来这段被注释掉了，已恢复。开发调试若不想要弹窗，把 `ContinueFromSplash` 改回直接 `EnterMainMenu(true)` 即可，但那样广告不会初始化。
