# 推广素材 AI 生图提示词（通用素材封面 / 详细推广图 竖版 / 横版）

> 用途：小游戏管理端「功能 - 游戏能力地图 - 运营素材管理」的通用素材配置。
> 玩法设定：三消（糖果甜品）/ 对对消-连连看（农场果蔬）/ 叠叠消（木质卡牌）三种休闲消除合集。

---

## 0. 先确认规格（出图前对齐，避免返工）

官方公开可查的《游戏实机素材指南》封面规范：横版 16:9 = 1920×1080、竖版 9:16 = 1080×1920、JPG、<500K。
「通用素材」三项的具体像素以上传页实际提示为准，**关键是比例要对**，下面按标准比例出图，导出时再按页面要求裁切压缩。

| 素材项 | 建议出图比例 | 建议像素 | 构图要点 |
|---|---|---|---|
| 通用素材封面 | 1:1（附 16:9 变体） | 1536×1536（或 1920×1080） | 单一视觉焦点，中心/上方留空给游戏名 |
| 详细推广图（竖版） | 9:16 | 1080×1920 | 上 1/4 留白放名字，中下展示棋盘 |
| 详细推广图（横版） | 16:9 | 1920×1080 | 左 1/3 留白放名字，右侧展示棋盘 |

本项目是**竖屏休闲游戏**，竖版推广图是主力素材，优先做好它。

---

## 1. 三玩法的视觉符号（三张图必须共用，否则不像同一个游戏）

| 玩法 | 视觉符号 | 主色 |
|---|---|---|
| 三消 | 圆角糖果方块 / 果冻方块，三连高亮描边 | 粉、薄荷绿、天蓝、柠檬黄 |
| 对对消（连连看） | 成对果蔬方块 + 一条折线连接的发光光带 | 橙、草绿、奶油白 |
| 叠叠消 | 三层错落堆叠的圆角卡牌 + 底部木质暂存槽 | 原木棕、奶白、暖橙 |

统一基调：马卡龙糖果色、扁平 + 轻 3D 卡通、明亮暖色背景、无写实、无暗黑。

## 6. 出图后必做的 5 步

1. **补游戏名**：AI 不出字。用 PS / 稿定 / 创客贴加中文游戏名，字体用圆体粗体 + 描边或外发光，保证在小尺寸下可读。
2. **裁切到目标比例**：1:1 / 9:16 / 16:9，注意主体不要被裁到边缘（出图时主体占比控制在 70% 以内）。
3. **压到 <500K**：导出 JPG，质量 80–85；若超限，先缩分辨率再压。
4. **查主体清晰度**：缩到 200px 宽看一眼，糊的、元素太多的直接弃（微信明确"避免画面过于复杂"）。
5. **查风格一致性**：三张图放在一起看，配色与造型必须像同一个游戏，否则换方案重出。

## 7. 红线检查表（微信素材审核）

| 禁止项 | 自查 |
|---|---|
| 除游戏名外出现任何文案（最新、最热、官方、免费、必玩…） | ☐ |
| 出现按钮、血条、分数面板等 UI 元素 | ☐ |
| 出现边框、黑边、加载/转场画面 | ☐ |
| 直接照搬游戏 icon 或游戏截图 | ☐ |
| 画面元素超过 2 个视觉焦点（硬性要求 1~2 个） | ☐ |
| 与实机画风落差过大（玩家会觉得"货不对板"） | ☐ |
| 使用无版权素材 / 含真人形象 / 含国旗地图等元素 | ☐ |
| 宣传图与实际玩法不符（不能出现游戏里没有的角色或玩法） | ☐ |

> 最后一条最容易被忽略：本项目**没有吉祥物**（方案 C 里的吉祥物是虚构的）。
> 如果用吉祥物做封面，建议后续在游戏内也加上它，或在提审备注里说明它是宣传形象。
