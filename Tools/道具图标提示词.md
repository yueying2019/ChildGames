# 三玩法道具图标 · 文生图提示词

所有道具图标共用一套风格后缀，保证一套图看起来是同一个游戏：
先复制「公共风格」，再拼上每个道具的「主体」，就是完整 prompt。

## 公共风格（每个 prompt 后面都接这段）

```
flat vector game UI icon, centered composition, square 1:1, white background,
rounded thick shapes, soft pastel palette, matte flat colors, clean soft outline,
casual puzzle game style, subtle drop shadow, high contrast silhouette,
no text, no letters, no watermark
```

负向提示（Negative）：

```
text, letters, words, watermark, realistic photo, 3d render, complex background,
gradient mesh, noisy texture, extra characters, blurry, low resolution
```

建议参数：1024×1024，图标主体占画面 70%，四周留白；导出 PNG 后裁成圆角，尺寸 128×128 用。
