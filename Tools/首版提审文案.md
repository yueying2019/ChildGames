## 六、本项目专属风险与对策

| 风险点 | 说明 | 对策 |
|---|---|---|
| 广告位保持为空 | `AdCatalog` 三个 ID 为空，激励复活和双倍金币按钮不会出现 | 提审包保持空串。真机走一遍失败复活和结算页，确认没有「看广告」 |
| 开发者窗口 | 主菜单版本号连点两次，口令 `kazihe666` 可清档、加金币、全解锁 | 提审包不要带这个入口。上传前确认版本号连点没有反应 |
| 声明与代码不一致 | 后台若勾了头像、位置等接口，但游戏没有这些调用，会被认为声明不符 | 后台隐私指引选「未处理用户个人信息」，不要勾选未使用的接口 |
| 教学关首现 | 首次点玩法直接进教学关 | 视频里务必拍到，否则审核员可能认为"玩法不明" |
| 备案状态 | 未备案无法提交审核 | 先确认备案通过再上传代码 |
| 字体版权 | 用 `NotoSansSC-UI`（SIL OFL，可商用） | 备注中写明"自制或已获授权可商用素材" |
| 无用户信息采集 | 后台勾选必须和实际调用一致 | 隐私指引选不采集。游戏内没有隐私同意弹窗，也不调用头像、昵称、位置、相册 |

### 7.4 写法规则

| 规则 | 说明 |
|---|---|
| 每条 = 模块 + 改动 + 测试路径 | 审核员能照着走一遍，就不会以"无法体验"驳回 |
| 动词开头 | 新增 / 优化 / 修复，别写"若干""一些" |
| 合规点单独成条 | 涉及金币、广告、隐私的改动必须写明，别让审核员猜 |
| 版本号递增 | `主.次.修订`；改代码就必须升版本，不能复用旧版本号 |
| 禁词 | 最、第一、史上、限时、免费领取、分享得奖励（诱导分享与广告法极限词） |
| 与审核备注的区别 | 更新说明 = 本次改了什么（验收清单）；审核备注 = 游戏是什么（说明书） |

## 八、若被驳回：按驳回类型改

| 驳回原因 | 处理 |
|---|---|
| 类目不符 | 改选「游戏 - 休闲益智/消除」，简介同步改 |
| 隐私接口未声明 | 后台补隐私指引，确认代码未调用 `getUserInfo`/`getLocation` |
| 广告相关驳回 | 本版本没有广告。说明未配置广告位，结算和复活处没有看广告按钮，并重录视频 |
| 无法完整体验 / 卡加载 | 补首包体积优化、弱网兜底，重录视频证明可玩 |
| 玩法说明不清 | 把 4.3 审核备注全文贴进补充说明并重录视频 |
| 资质不全 | 按后台提示补软著证书或《游戏内容自审自查报告》，注意证书名称与游戏名一致 |
